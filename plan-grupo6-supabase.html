El ejemplo: mini catálogo de productos

Propuesta: una sola página index.html conectada a Supabase

Es exactamente el proyecto sugerido por la profe: una tabla productos con id, nombre, precio y categoria. La página muestra los productos guardados en Supabase y tiene un formulario para agregar uno nuevo.

No hay que instalar nada: la librería de Supabase se carga desde un CDN con una etiqueta <script>. Los compañeros solo necesitan una cuenta gratis de Supabase, un navegador y VS Code (o cualquier editor). Sin Node, sin npm, sin permisos de administrador en las computadoras del laboratorio.

Paso 3 · Crear la tabla con SQL

Persona B

En el menú izquierdo: SQL Editor → pegar este script → Run. Luego abrir Table Editor para ver la tabla con sus 3 filas.

sql/01_crear_tabla.sql
-- 1. Crear la tabla (PostgreSQL)
create table productos (
  id        bigint generated always as identity primary key,
  nombre    text not null,
  precio    numeric(10,2) not null check (precio >= 0),
  categoria text not null
);

-- 2. Seguridad: activar RLS y permitir leer e insertar a la app
alter table productos enable row level security;

create policy "Leer productos" on productos
  for select to anon using (true);

create policy "Agregar productos" on productos
  for insert to anon with check (true);

-- 3. Datos de ejemplo (precios en colones)
insert into productos (nombre, precio, categoria) values
  ('Café chorreado', 1200, 'Bebidas'),
  ('Gallo pinto',    2500, 'Comidas'),
  ('Tres leches',    1800, 'Postres');

-- 4. Consulta de prueba
select * from productos where categoria = 'Bebidas';

Qué explicar en 1 minuto: create table y los tipos de dato, la llave primaria que se numera sola, y que RLS (Row Level Security) bloquea todo por defecto; las dos políticas le dan permiso a la página de leer e insertar. En un sistema real no se deja insertar a cualquiera; aquí es para aprender.

12:00–14:00

Paso 4 · Conectar la página con el proyecto

Persona C

En Supabase: botón Connect (arriba) o Project Settings → API Keys. Copiar la Project URL y la publishable key (o la anon key si aparece esa). Pegarlas en las dos constantes de index.html:

practica/index.html
<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
<script>
  const SUPABASE_URL = 'https://xxxxxxxx.supabase.co';
  const SUPABASE_KEY = 'pegar-aquí-la-publishable-key';

  // Ojo: no llamarlo "supabase", ese nombre ya lo usa la librería
  const cliente = window.supabase.createClient(SUPABASE_URL, SUPABASE_KEY);
</script>
Nunca pegar la secret key ni la service_role key en el HTML: esas saltan las políticas de seguridad.

async function cargarProductos() {
  const { data, error } = await cliente

async function agregarProducto(evento) {
  evento.preventDefault();
  const nuevo = {
    nombre: formulario.nombre.value,
    precio: Number(formulario.precio.value),
    categoria: formulario.categoria.value
  };

  const { error } = await cliente.from('productos').insert(nuevo);

  if (error) { mostrarError(error); return; }
  formulario.reset();
  cargarProductos();
}
